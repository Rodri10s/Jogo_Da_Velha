# Jogo da Velha em Java – IFBA

Este repositório armazena o código-fonte do projeto **Jogo da Velha** desenvolvido por **Ramon Rodrigues Silva**, aluno do 4º ano do curso técnico integrado de Informática do **Instituto Federal da Bahia (IFBA)**.

## Sobre o Repositório

O projeto consiste na implementação do clássico jogo da velha (tic-tac-toe) utilizando a linguagem **Java**. O objetivo é praticar conceitos fundamentais de programação, lógica, estrutura de dados e desenvolvimento orientado a objetos, conforme estudados no curso técnico.

## O que você encontra aqui?

- **Implementação do Jogo da Velha:** Código completo para jogar no terminal, com funcionalidades de controle de jogadas, verificação de vitória/empate e interface textual.
- **Exercícios de Programação:** Explora técnicas de manipulação de matrizes, controle de fluxo, entrada e saída de dados e modularização de código.
- **Resolução de Problemas Práticos:** O projeto propõe e resolve desafios típicos de jogos simples, como validação de movimentos, alternância entre jogadores e detecção do final da partida.

## Problemas Resolvidos

- Criação de uma matriz para representar o tabuleiro do jogo.
- Alternância de jogadores e validação de entradas.
- Verificação automática de vitória, empate ou continuidade da partida.
- Prática de boas práticas de codificação e organização de projetos Java.
